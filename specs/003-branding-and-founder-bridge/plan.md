## Phase 0: Research (Complete)

The full codebase was indexed prior to planning. Key findings:

### CSS Architecture Observations

- **`body::before`** (lines 106–125): Handles fixed background (overlay gradient + profile photo). Uses `background-size: auto 100vh; background-position: right; background-repeat: no-repeat`. **Not modified** by this feature.
- **`body::after`**: Currently **unused** — available for the watermark pseudo-element.
- **`.nav-brand`** (lines 300–304): Contains `font-size: var(--lg-typography-size-xl); font-weight: 700; color: ...`. These properties become irrelevant (not harmful) once the inner content is replaced with an `<img>`. The `.nav-logo` rule uses `height: 36px` to size the image.
- **`.hero-tagline`** (lines 340–344): Has `margin-bottom: 1.5rem`. After removing the `.button-primary`, the `.hero-cta` replaces it with `margin-top: 1.5rem` on the new container — net spacing is preserved.
- **Global `a` rule** (lines 133–147): Default `color: var(--lg-color-accent-primary)` (teal). `.hero-cta-link` must **override** this to `color: var(--lg-color-text-muted)` (mist) as its default — otherwise the teal default takes precedence.
- **Mobile nav** (lines 621–624): At ≤768px, `.nav` is `flex-direction: column` and `.nav-links` retains `display: flex; gap: 1rem`. Four links ("meet the founder" is long text) may overflow. A `flex-wrap: wrap` addition to `.nav-links` in the mobile block is prudent.
- **`@media (max-width: 768px)` block** (lines 608–652): Already contains `body::before { background-size: cover }`. The `body::after { display: none }` watermark suppression will be added here.

### HTML Structure Observations

- **`.nav-brand`** (line 25): `<div class="nav-brand">Metamatopoeia</div>` — text content replaced with `<img>`.
- **`.nav-links`** (lines 26–51): Three `<li>` items. Fourth inserted between workshop and contact.
- **`.hero-card`** (lines 61–69): Contains `<p class="hero-tagline">` then `<a class="button button-primary">`. The button is removed; `.hero-cta` div replaces it.
- **JS `<script>` block** (lines 343–370): 13 non-empty source lines. **Untouched.**

### Risk Assessment

| Risk                                                 | Severity | Mitigation                                                                           |
| ---------------------------------------------------- | -------- | ------------------------------------------------------------------------------------ |
| Global `a` color overrides `.hero-cta-link`          | Medium   | Explicitly set `color` in `.hero-cta-link` rule with sufficient selector specificity |
| Mobile nav overflow with 4 links                     | Low      | Add `flex-wrap: wrap` to `.nav-links` in `@media (max-width: 768px)`                 |
| `body::after` z-index conflict with cards            | Low      | Use `z-index: -1` matching `body::before`; both are below all content                |
| Watermark PNG at full natural opacity looks too bold | Low      | `opacity: 0.45` on `body::after` applies uniformly to the pseudo-element             |
