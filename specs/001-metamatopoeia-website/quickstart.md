## Implementation Steps

### Step 1: Create Assets Directory

```bash
mkdir -p assets
```

### Step 2: Copy Assets from Reference Repository

Copy the following assets from `sds-smith/html_portfolio`:

- Background image: `background-image-profile.jpeg` → `./assets/background-image-profile.jpeg`
- Card media images: `card-media-cup.png`, `card-media-liquid-glass-ui.png`, `card-media-discover-breweries.png`, and `card-media-atj.png` → `./assets/`

### Step 3: Create index.html

Follow the HTML structure contract in `contracts/html-structure.md`. Key points:

- Single `<!DOCTYPE html>` document
- Semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`)
- Three sections: Hero (`#hero`), Workshop (`#workshop`), Contact (`#contact`)
- Four project cards in Workshop section
- Three contact channels in Contact section
- SpeedDial FAB with no more than 30 non-empty source lines of vanilla JavaScript
- No external CDN resources or network requests
- All colors derive from the four palette tokens

### Step 4: Create index.css

Follow the CSS structure contract in `contracts/css-structure.md`. Key points:

- CSS custom properties for the four palette tokens, RGB channel tokens, and semantic color aliases
- Liquid Glass design tokens with `--lg-{group}-{subgroup}-{token}` naming
- Mobile-first responsive design
- Dark mode via `prefers-color-scheme`
- Reduced motion via `prefers-reduced-motion`
- Reduced transparency via `prefers-reduced-transparency`
- No hardcoded colors (all from palette tokens)
- Single stylesheet, no preprocessors

### Step 5: Test the Site

Open `index.html` directly from the filesystem in a browser:

```bash
# Linux/Mac
open index.html

# Windows
start index.html
```

**Verification Checklist**:

- [ ] Page loads without errors
- [ ] All three sections are visible
- [ ] Navigation links scroll to correct anchors
- [ ] Four project cards render with images
- [ ] SpeedDial FAB toggles open/closed
- [ ] Contact links resolve correctly
- [ ] Zero external network requests (check DevTools Network tab)
- [ ] Responsive on mobile (<768px)
- [ ] Very narrow viewport works at 280px and 320px without horizontal overflow
- [ ] Dark mode works (enable in OS settings)
- [ ] Reduced motion works (enable in OS settings)
- [ ] Reduced transparency works (enable in OS settings)
- [ ] Reduced motion and reduced transparency work together
- [ ] Unsupported backdrop-filter fallback remains readable
- [ ] Missing image fallback leaves project cards stable with descriptive alt text available
- [ ] Keyboard navigation works (Tab through page)

## Key Constraints to Remember

### Color Palette (NON-NEGOTIABLE)

All colors MUST derive from these four tokens:

```css
--color-slate: #5a606a; /* Primary dark / text */
--color-teal: #79a1a2; /* Accent / interactive */
--color-mist: #bdbfc6; /* Mid-tone / borders */
--color-frost: #eff1f3; /* Light surface / bg */
```

**No other hex, rgb, hsl, or named color values permitted.**
Alpha colors must use palette channel tokens, for example `rgb(var(--color-slate-rgb) / 0.85)`.

### Liquid Glass Design Tokens

Naming convention: `--lg-{group}-{subgroup}-{token}`

Examples:

- `--lg-glass-blur`
- `--lg-glass-bg-opacity`
- `--lg-glass-shadow-md`
- `--lg-typography-size-base`
- `--lg-layout-breakpoint-tablet`

### JavaScript Limit

Maximum 30 non-empty source lines of vanilla JavaScript for the SpeedDial FAB only, excluding `<script>` tags and blank lines. No frameworks, no separate `.js` files.

### Zero External Dependencies

- No CDN resources
- No web fonts
- No remote images
- No analytics scripts
- No build tools
- No CSS preprocessors

### Brand Standards

- Brand name: "Metamatopoeia" only (no personal names)
- Contact channels: Email, GitHub, LinkedIn only
- No About section or personal content

## Troubleshooting

### Issue: Background image not loading

**Solution**: Verify the path in `body` background-image matches the actual file location in `./assets/`.

### Issue: Colors not displaying correctly

**Solution**: Ensure all color values use `var(--color-*)` tokens. Check for any hardcoded hex values that violate the palette constraint.

### Issue: Glass effects not working

**Solution**: Verify `backdrop-filter` and `-webkit-backdrop-filter` are present. Check that `--lg-glass-blur` token is defined.

### Issue: SpeedDial FAB not toggling

**Solution**: Verify the checkbox input has matching `id` and label `for` attributes. Check that the JavaScript is at the end of `<body>`.

### Issue: External network requests detected

**Solution**: Check for any CDN links, web fonts, or remote image URLs. All assets must be local.

### Issue: Dark mode not working

**Solution**: Verify the `@media (prefers-color-scheme: dark)` block is present and overrides the correct tokens.
